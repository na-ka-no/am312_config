# am312_config

AM312 人感センサー + XIAO BLE で、人が近づいたらキー操作を送る ZMK ファームウェア。

## 配線

| 部品 | 部品側の端子 | つなぐ先 |
|---|---|---|
| AM312 | VCC / GND / OUT | XIAO 3V3 / GND / D0 |
| スイッチA（モード1） | 2本の足（向きなし） | XIAO D1 と GND |
| スイッチB（モード2） | 2本の足（向きなし） | XIAO D2 と GND |
| 昇圧モジュール（aaa-boost-module-v2） | 1 GND | XIAO GND、電池− |
| | 2 5V | XIAO 5V（USB 接続時の逆流防止に必須） |
| | 3 SNS | XIAO D3（電池残量の測定） |
| | 4 MCU | XIAO 裏面の BAT+ パッド |
| | 5 BAT | 電源スイッチ → 電池+（エネループ単4 1本） |

- LED は XIAO 基板上のフルカラーLEDの緑と青を使う（配線不要）。
- D4・D5・D6〜D10 は空き。
- 電池残量はニッケル水素用の換算表（`src/battery_nimh.c`）で計算し、Bluetooth で PC に送る（Windows の「Bluetooth とデバイス」に表示される）。

## 本体の操作

| 操作 | 動作 |
|---|---|
| センサー反応 | 今のモードのキーを送る。次に反応できるまでモードの色でLEDが点く |
| スイッチA / B 単押し | 動作確認（今のモードのキーを送り、モードの色でLEDが点滅） |
| スイッチA 3秒長押し | モード1（緑）にする |
| スイッチB 3秒長押し | モード2（青）にする |
| 両方 単押し | センサー反応時のLED表示を ON / OFF |
| 両方 3秒長押し | Bluetooth のペアリング情報をすべて消す |

LED の色はモード1が緑、モード2が青。電源を入れた直後は電池残量を2秒間表示する（50%以上：緑、20〜49%：黄、20%未満：赤。電池がないときは表示しない）。ペアリング削除のときは緑と青が同時に点滅する（水色に見える）。モードと LED の ON/OFF は電源を切っても保たれる。

## 送るキーを変える

1. [docs/index.html](docs/index.html) をブラウザで開く
2. モードごとに送るキーの手順を決めて「設定ファイルをダウンロード」を押す
3. XIAO BLE のリセットボタンを2回押し、出てきたドライブに `pir_config.uf2` をコピーする

設定ファイルはフラッシュの設定領域（`0xE9000`、4KB）だけを書き換えるので、ファームウェア本体を書き直す必要はない。
ファームウェアを更新しても設定は残る。初期設定に戻すときは「初期設定に戻すファイル」を書き込む。

## 構成

| パス | 内容 |
|---|---|
| `config/boards/shields/pir_switch/` | シールド定義（配線・キーマップ・設定領域） |
| `src/behavior_pir_switch.c` | センサー・スイッチ・LED・設定領域を扱う ZMK の動作 |
| `src/battery_nimh.c` | エネループ1本の電池残量を測るセンサー |
| `include/dt-bindings/zmk/pir_switch.h` | キーマップで使うコマンド（`PIR_TRIGGER` など） |
| `dts/bindings/`, `Kconfig`, `CMakeLists.txt`, `zephyr/module.yml` | 上の動作を ZMK に組み込むための定義 |
| `docs/index.html` | 設定ファイル（.uf2）を作る Web ページ |

本体の操作

    

      
電源を入れた直後電池残量をLEDの色で2秒間表示（50%以上：緑、20〜49%：黄、20%未満：赤）

      
センサー反応今のモードのキーを送る。次に反応できるまで、本体のLEDがモードの色で光る（モード1：緑、モード2：青）

      
スイッチA 単押し動作確認（今のモードのキーを送り、モードの色でLEDが点滅）

      
スイッチA 3秒長押しモード1（緑）にする

      
スイッチB 単押し動作確認

      
スイッチB 3秒長押しモード2（青）にする

      
両方 単押しセンサー反応時のLED表示を ON / OFF（ON：2回点滅、OFF：1回長く点灯）

      
両方 3秒長押しBluetooth のペアリング情報を消す（LEDが水色で5回点滅）。パソコン側でも「PIR Switch」を削除してから、ペアリングし直してください
